📋 Command cheat sheet

Every everyday command, one page

Grouped by what you're trying to do. Type to filter (try undo, branch, remote, stash…). Commands tagged rewrites change history or discard work: think before using them on shared branches.

Aliases worth adding

~/.gitconfig
[alias]
  st   = status -sb
  lg   = log --oneline --graph --decorate --all
  last = log -1 HEAD --stat
  undo = reset --soft HEAD~1            # uncommit, keep changes staged
  amend = commit --amend --no-edit
  wip  = !git add -A && git commit -m wip
[pull]
  rebase = true
[push]
  autoSetupRemote = true                # first push of a branch sets upstream
[fetch]
  prune = true
[merge]
  conflictstyle = zdiff3
[rerere]
  enabled = true                        # remember how you resolved a conflict
Built with python build.py. Commands target git 2.4x+ (git switch / git restore exist since 2.23) and GitLab 17 / 18 (CI/CD components, rules, needs).
