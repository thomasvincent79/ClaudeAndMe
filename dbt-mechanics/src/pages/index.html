How to regenerate the pages

Edit the sources in src/pages/*.html and src/js/*.js, then run python build.py (or python build.py --serve to also serve them on localhost:8800). To add a topic (for example "sources & freshness" or "materializations"), add a fragment and one entry in THEMATICS in build.py.
