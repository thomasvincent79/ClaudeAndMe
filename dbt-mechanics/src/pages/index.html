dbt mechanics, visually

One page per dbt topic. Each page has interactive simulators with concrete data and a "when to use what" section. Everything is written for two dbt Core versions at once: 1.8.6 (what you run today) and 1.12 (current v1). Use the switch at the top right to show one version or compare both.

How to regenerate the pages

Edit the sources in src/pages/*.html and src/js/*.js, then run python build.py (or python build.py --serve to also serve them on localhost:8800). To add a topic (for example "sources & freshness" or "materializations"), add a fragment and one entry in THEMATICS in build.py.
